# Python Data Visualization with Matplotlib & SQLite

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![Matplotlib](https://img.shields.io/badge/Matplotlib-3.8%2B-orange.svg)](https://matplotlib.org/)
[![SQLite](https://img.shields.io/badge/SQLite-3-lightgrey.svg)](https://www.sqlite.org/)

A Python project demonstrating relational data extraction from **SQLite** and custom statistical visualization rendering using **Matplotlib**.

---

## 🚀 Key Features

* **Relational Database Querying**: Uses `sqlite3` for transactional query execution and data extraction.
* **Custom Plot Rendering**: Generates formatted multi-line charts with gridlines, custom styling, DPI scaling, and legends.
* **Automated Mock Database Provisioning**: Automatic schema creation and seed data insertion for immediate testing execution.
* **Resource Management**: Explicit memory and plot figure cleanup (`plt.close()`) after disk export.

---

## 🛠️ Tech Stack

* **Language**: Python 3.10+
* **Data Visualization**: Matplotlib
* **Database**: SQLite3

---

## ⚙️ Configuration & Setup

### 1. Clone the repository
git clone https://github.com/DrRafael/python-data-visualization-matplotlib.git
cd python-data-visualization-matplotlib

### 2. Install dependencies
pip install -r requirements.txt

### 3. Run the visualization script
python main.py
